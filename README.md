## Repository

```
src/prompts.py      the shared serializer — imported by train AND eval, never copied
src/config.py       experiment schema; catalog is an eval axis, never a train field
src/invariants.py   assertions that abort a run rather than produce plausible garbage
src/runlog.py       append-only JSONL with per-cell resume (sessions die at 12h)
configs/            one YAML per experiment cell, all extending base.yaml
results/            raw run JSON, never hand-edited
```

### Working rules

- Every script takes `--smoke`: same code path, tiny inputs, under two minutes.
- `make preflight` before any job over an hour.
- A stub refuses to run without `--smoke`, so it cannot be mistaken for a
  working pipeline.
- Changing `src/prompts.py` changes its hash and aborts every run until the pin
  in `configs/base.yaml` is updated. That is intentional: prompt-format drift
  between train and eval is the top-ranked silent failure in this project.
